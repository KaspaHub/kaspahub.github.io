Convert Kaspa name owner wallet address

Paste a 32-byte owner identifier, or paste a wallet address to decode it back to the owner payload. For a normal key owner use version 0 (PubKey). Conversion runs in your browser.

Kaspa names APIs often return an owner field as raw hex rather than a kaspa: address. This tool encodes that payload with the selected address version and network prefix using the Kaspa bech32 checksum, or decodes an address back to hex, version, prefix, and payload length.
